# Structured Share Thing

## 목적

어떤 문제를 처음 접하는 윗사람이나 다른 팀에게, 사용자가 이미 정한 진행 방향을 알리는 공유 메시지 초안을 씁니다. 메시지의 성격은 "이렇게 진행하겠습니다. 정말 문제가 되면 말려 주세요"입니다. 승인을 요청하는 글이 아닙니다.

## 쓰기 전에 모을 것

대화, 문서, 메모에서 아래 항목을 찾습니다. 없는 항목은 지어내지 않고, 초안 아래에 "확인 필요"로 적습니다.

- 받는 사람과 그 사람이 이미 아는 것
- 문제: 무엇이 안 되는가
- 중요성: 해결하지 않으면 누가 어떤 손해를 보는가
- 경위: 그동안 왜 막혀 있었는가(있을 때만)
- 진행 방향: 무엇을 어떤 단계로 하는가
- 현재 상황: 끝난 것과 남은 것
- 예외: 이 방향이 통하지 않는 조건과 그때의 대안

## 프레임

받는 사람이 처음 읽는다는 전제로 아래 순서를 지킵니다. 해당 내용이 없는 절은 빼되, 순서는 바꾸지 않습니다.

```
[공유] <주제를 한 줄로>

<받는 사람>님, <배경 한 문장: 언제 무엇이 시작되는지>. 이 과정에서 생긴 <문제 이름>과 진행 방향을 공유드립니다.

*1. 무엇이 문제인가*
• <현상>
• <원인: 왜 그대로는 안 되는지>

*2. 왜 해결해야 하는가*
• <해결하지 않으면 생기는 손해. 고객, 매출, 일정처럼 받는 사람이 신경 쓰는 단위로>
• <이미 정해진 정책이나 전제가 있으면 여기>

*3. 그동안 막혀 있던 이유*   ← 경위가 있을 때만
• <시도한 것과 막힌 지점, 누가 그렇게 판단했는지>

*4. 진행 방향: <방향을 한 구절로>*
<이 방향이 3번의 막힌 지점을 어떻게 피하는지 한 문장>
• *1단계 <이름> (<시점>):* <무엇을 하는지>
• *2단계 <이름> (<시점>):* <무엇을 하는지, 최종 형태인지>

*5. 현재 진행 상황*
• <끝난 것>: <상태>
• <남은 것>: <무엇만 남았는지, 끝나면 무엇이 가능한지>

*6. 이 방식이 안 되는 경우*
1. *<조건>:* <무슨 일이 생기는지 쉬운 말로>
2. ...
→ <그때의 대안 한두 문장>

이 방향으로 진행하겠습니다. 혹시 문제가 될 만한 부분이 보이시면 말씀 부탁드립니다.

자세한 내용은 <문서>에 정리했습니다: <링크>
```

## 규칙

- **결론이나 내 작업부터 꺼내지 않습니다.** "정리했습니다", "결론부터 말씀드리면", "~방식으로 진행 중입니다"로 시작하지 않습니다. 첫 문단은 배경과 이 메시지가 무엇을 다루는지만 말합니다.
- **승인을 요청하지 않습니다.** "승인 요청", "결정 부탁드립니다", 체크리스트를 넣지 않습니다. 마무리는 "이 방향으로 진행하겠습니다. 문제가 될 만한 부분이 있으면 말씀 부탁드립니다"처럼 진행을 알리고 이견만 열어 둡니다. 사용자가 승인 요청을 원한다고 하면 그때만 바꿉니다.
- **처음 읽는 사람 기준으로 씁니다.** 약어, 장비명, 내부 용어는 처음 나올 때 괄호로 풀어 씁니다. 예: SBC(통화 중계 장비). 받는 사람이 모르는 사람 이름은 팀명과 함께 씁니다.
- **예외는 "조건: 결과" 한 줄로 씁니다.** 기술 원리보다 받는 사람이 겪을 결과를 씁니다. 예: "고객 번호 대신 회사 번호가 보이면, 누가 걸었는지 알 수 없고 콜백도 못 합니다."
- **사실과 판단을 구분합니다.** 확인되지 않은 것은 "~할 가능성이 큽니다", "확인 중입니다"로 씁니다. 근거 없는 판단을 넣었으면 초안 아래에 알려 줍니다.
- **Slack 형식으로 씁니다.** 굵게는 `*텍스트*`, 목록은 `•`와 `1.`로 쓰고 Markdown 제목(`#`)은 쓰지 않습니다. 한 항목은 한두 줄로 씁니다.
- **보내지 않습니다.** 초안만 답변에 쓰고, 사용자가 명시적으로 요청할 때만 전송 도구를 씁니다.

## 답변 형태

1. 한 줄로 무엇을 썼는지 말합니다.
2. `---` 사이에 초안 전문을 넣습니다.
3. 초안 아래에 보내기 전에 사용자가 할 일만 짧게 적습니다. 예: 링크 교체, 문서 공유 권한, 확인 필요 항목, 근거 없이 쓴 판단.

수정 요청을 받으면 초안 전문을 다시 주고, 무엇이 바뀌었는지 한두 줄로 덧붙입니다.
