# 헬프데스크 매크로 변수

매크로 본문에 아래 토큰을 넣으면 발송 시 고객 정보로 치환됩니다. 토큰은 중괄호 두 개로 감쌉니다.

| 토큰 | 내용 | 상태 |
|---|---|---|
| `{{customer_name}}` | 고객 이름 | 사용 가능 |
| `{{order_id}}` | 주문번호 | 사용 가능 |
| `{{refund_amount}}` | 환불 예정 금액(원) | 사용 가능 |
| `{{payment_method}}` | 결제 수단(예: 신용카드) | 사용 가능 |
| `{{refund_link}}` | 환불 상세/진행 상황 페이지 링크 | 사용 가능 |
| `{{refund_status_url}}` | (구) 환불 조회 링크 | 폐기 — 2026-09부터 404 |
| `{{agent_name}}` | 상담원 이름 | 사용 가능 |
