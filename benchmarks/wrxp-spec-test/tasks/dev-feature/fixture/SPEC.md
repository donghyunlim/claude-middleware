# parse_duration 명세

`timeutil.duration.parse_duration(text: str) -> int` 은 사람이 쓴 기간 문자열을 초 단위 정수로 바꾼다.

## 형식
- 단위: `d`(일), `h`(시간), `m`(분), `s`(초). 대소문자를 구분하지 않는다.
- 각 단위는 정수(0 이상)와 함께 쓴다. 예: `1h30m`, `2d`, `45s`, `1d2h3m4s`.
- 단위 사이에 공백이 하나 이상 있어도 된다: `1h 30m`. 앞뒤 공백은 무시한다.
- 단위는 반드시 큰 단위에서 작은 단위 순서(d → h → m → s)로 쓰고, 같은 단위를 두 번 쓸 수 없다.
- 단위 없는 정수 하나만 있으면 초로 본다: `"90"` → 90.

## 거부(ValueError)
- 빈 문자열이나 공백만 있는 문자열
- 모르는 단위(`1x`), 숫자 없는 단위(`h`), 음수·소수(`-5s`, `1.5h`)
- 순서가 틀리거나 단위가 중복된 경우(`30m1h`, `1h2h`)
- 단위 없는 숫자와 단위를 섞은 경우(`1h30`)
- 결과가 365일(31,536,000초)을 넘는 경우. 정확히 365일은 허용한다.
- `str`이 아닌 입력은 TypeError
