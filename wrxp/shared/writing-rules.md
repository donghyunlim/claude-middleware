# Writing Rules

`/ha` 글쓰기·기획서 트랙에서 산출물을 쓰는 동안 지키는 공통 규칙이다. 다른 작업에서는 호출한 skill이 가리킬 때만 읽는다. 한국어 산출물은 마지막에 `wrxp:korean-polish`로 교정한다.

## 언어와 무관한 규칙

- 제목은 요지를 담는다. "검토 결과"보다 "결제 실패는 재시도 설정 누락 때문이다"처럼 쓴다.
- 한 대상에는 한 이름만 쓴다. 같은 것을 문단마다 다른 말로 부르지 않는다.
- 구체적으로 쓴다. "일부", "여러 곳", "개선"보다 실제 대상·수치·위치를 적는다.
- 출처 없는 권위에 기대지 않는다. "일반적으로 알려진", "업계 표준"이라고 쓰려면 출처를 붙이고, 없으면 쓰지 않는다.
- 개수는 실제 개수대로 쓴다. 항목이 둘이면 "세 가지"로 맞추지 않는다.

## 한국어 공통 규칙

- 주체와 대상을 생략하지 않는다. 문맥을 이해하는 데 필요한 주체, 대상, 조건과 영향 범위를 밝힌다.
- 일반 문장은 서술어와 종결어미를 갖춘 완결된 문장으로 끝낸다. 제목, 표, 레이블과 짧은 목록 항목은 예외다.
- 널리 통용되는 정확한 어휘를 쓴다. 불필요한 비유·과장·희귀어를 피한다.
