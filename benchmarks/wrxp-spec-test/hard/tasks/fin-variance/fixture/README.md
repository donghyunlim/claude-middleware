# 재무팀 비용 데이터 (2026-11-03 추출)

## 파일
- `budget_q3.csv`: 2026년 3분기(7~9월) 부서별 비용 예산(원). 예산은 사업계획 환율 1,350원/USD로 편성했다.
- `expenses.csv`: 2026-06 ~ 2026-10 송장 기준 비용 전표. 1행이 전표 1건이다.
  - `invoice_date`: 송장(세금계산서) 발행일, `paid_date`: 실제 지급일
  - `amount`: `currency` 통화 기준 금액 (KRW는 원, USD는 달러)
  - `status`: `정상` 또는 `취소`. `취소` 전표는 발행 후 무효 처리된 전표다.
- `fx_month_end.csv`: 서울외국환중개 월말 매매기준율 (USD/KRW).
