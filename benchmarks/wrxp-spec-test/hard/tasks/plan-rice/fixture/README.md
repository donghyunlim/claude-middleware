# 2027년 1분기 제품 백로그

`backlog.csv`는 PM들이 각자 적어 낸 백로그 후보다. 1행이 항목 1개다.

| 열 | 설명 |
|---|---|
| reach | 영향을 받는 사용자 수 추정치 |
| reach_period | reach를 추정한 기간. 작성자마다 월/분기/연으로 다르게 적었다. |
| impact | 사용자 1명당 영향 크기. 3=매우 큼, 2=큼, 1=보통, 0.5=작음, 0.25=아주 작음 |
| confidence_pct | 작성자가 적은 추정치에 대한 확신(%) |
| user_research | 사용자 인터뷰·설문 등 리서치 근거가 있는지 (Y/N) |
| team_size | 투입 인원(명) |
| duration | 예상 기간. 회사 기준으로 1개월 = 4주 = 20영업일, 1주 = 5영업일이다. |
