# 견적 할인 정책 (영업팀 내부용, 2026-07 개정)

## 1. 할인 대상
- 할인은 **구독 상품(좌석·애드온)** 금액에만 적용합니다.
- 온보딩·이관 등 일회성 서비스는 할인 대상이 아닙니다.

## 2. 좌석 수 할인
| 좌석 수 | 할인율 |
|---|---|
| 1–49 | 0% |
| 50–99 | 5% |
| 100–199 | 10% |
| 200 이상 | 15% |

## 3. 약정 기간 할인
| 약정 | 할인율 |
|---|---|
| 1년 | 0% |
| 2년 | 6% |
| 3년 | 12% |

## 4. 적용 방법
- 좌석 할인과 약정 할인은 **합산**하여 적용합니다. 단, 합산 할인율은 **최대 20%**를 넘을 수 없습니다.
- 2026년 상반기 신규 도입 프로모션(추가 5%)은 2026-06-30에 종료되었습니다.

## 5. 금액 표기
- 견적서의 공급가액은 할인 적용 후 **천 원 미만 절사**(끝전 할인)합니다.
- 부가세(10%)는 공급가액 기준으로 별도 표기하며, 원 미만은 절사합니다.

## 6. 견적 유효기간
- 기본 14일. 영업팀장 승인 시 최대 30일까지 가능합니다.
