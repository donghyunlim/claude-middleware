# 신규 입사자 온보딩 정책 (인사팀, 2026-03 개정)

1. **정보보안 교육**: 모든 신규 입사자는 입사 첫날 가장 먼저 정보보안 교육을 이수한다. 교육 이수 전에는 사내 계정·노트북·저장소 접근 권한을 발급하지 않으므로, 개발 환경 설정 등 계정이 필요한 일정은 반드시 보안 교육 뒤에 둔다.
2. **전사 신규 입사자 오리엔테이션**: 매월 둘째 주 수요일 14:00에 본사에서 열린다. 해당 월 입사자는 참석한다.
3. **휴무일**: 회사 휴무일과 공휴일은 `holidays_2026.csv`를 따른다. 휴무일에는 어떤 일정도 잡지 않는다.
4. **근무 형태**: 사무실 출근·재택 요일은 팀별로 정하며 담당 팀장이 온보딩 일정에 반영한다.
5. **멘토**: 신규 입사자마다 같은 팀 멘토 1명을 지정한다. 멘토 1:1 주기는 팀장이 정한다.
