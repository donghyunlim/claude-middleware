# 회원가입 폼 디자인 명세 v1.2 (디자인팀)

## 화면
`signup.html` 한 파일(외부 CSS/JS·CDN 없이 인라인)로 회원가입 폼을 만든다.

## 필드
1. 이메일 (필수, 이메일 형식)
2. 비밀번호 (필수, 8자 이상) — 아래에 보조 문구 "영문·숫자 포함 8자 이상"
3. 이용약관 동의 체크박스 (필수)
4. "가입하기" 버튼

## 동작
- 빈 칸이나 형식 오류로 제출하면 각 필드 아래에 오류 문구를 보여 주고 서버 전송은 하지 않는다.
- 오류 문구는 스크린리더가 해당 필드와 연결해 읽을 수 있어야 한다.
- 키보드만으로 모든 조작이 가능해야 하고, 포커스 위치가 눈에 보여야 한다.
- 폭 360px 모바일에서 가로 스크롤이 생기면 안 된다.

## 디자인 토큰 (이 색만 사용)
| 토큰 | 값 | 용도 |
|---|---|---|
| color.bg | #FFFFFF | 배경 |
| color.text | #1F2328 | 본문 |
| color.primary | #1F5FD1 | 버튼 배경, 포커스 링 |
| color.onPrimary | #FFFFFF | 버튼 글자 |
| color.error | #C62828 | 오류 문구·오류 테두리 |
| color.border | #8C959F | 입력창 테두리 |
| color.hint | #A0A7B0 | 보조 문구 |

## 접근성
- WCAG 2.2 AA를 지킨다(본문 크기 텍스트 명암비 4.5:1 이상).
